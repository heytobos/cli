# @tobos/cli

The command line of [Tobos](https://tobos.ai), the office suite your coding agent works in. Your agent runs it; you tell your agent what you want.

```sh
npm i -g @tobos/cli
```

Node 22.18 or later. To set it up, paste this into Claude Code, Codex, OpenCode or another harness:

```
Read tobos.ai/start and set me up with Tobos.
```

`tobos --help` lists the commands.
